# Alyona's Lyink page

Это первая готовая версия страницы на основе структуры Lyink: статический HTML без сборки и зависимостей.

## Что уже настроено
- VK, Telegram, TikTok, YouTube, Pinterest
- запись на урок — последней кнопкой
- фирменная палитра Алёны: #2772A7, #B4E0FF, #FFDCAF
- мобильная адаптация
- SEO title/description
- CTA выделена тёплым цветом

## Как разместить
1. Создай новый GitHub repository.
2. Загрузи `index.html` и `config.json`.
3. В Settings → Pages выбери Deploy from branch → main → root.
4. Через несколько минут GitHub Pages выдаст адрес сайта.

## Важно
В исходном Lyink стандартного VK icon нет, поэтому здесь для VK использована аккуратная текстовая иконка. При желании её можно заменить на фирменный SVG.

- `avatar.jpg` — загруженная фотография для аватара
